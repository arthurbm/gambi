O Gambi permite que um grupo compartilhe os modelos de IA e os agentes de código que já rodam na máquina de cada pessoa. Uma máquina roda um **hub**. Todo o resto entra em uma **sala** nesse hub e compartilha o que tem: um modelo servido pelo Ollama, pelo vLLM ou por uma API na nuvem, ou um agente de código como Claude Code, Codex ou OpenCode. Seu app então alcança todos eles pelo hub.

Chaves e logins nunca saem da máquina a que pertencem, e o hub nunca se conecta à máquina de ninguém. Cada participante abre uma conexão com o hub, e o hub envia o trabalho de volta por ela.

## As peças

  m1 -->|"túnel"| hub

| Peça | O que é |
| --- | --- |
| **Hub** | O processo iniciado por `gambi hub serve`. Ele mantém a lista de salas e participantes e roteia as requisições. Não precisa de GPU. |
| **Sala** | Um grupo dentro do hub, identificado por um código curto como `ABC123`. Toda requisição tem como alvo uma sala. |
| **Participante** | Uma coisa que alguém compartilha em uma sala. É um **modelo** ou um **harness**. |
| **Participante de modelo** | Um modelo por trás de um servidor compatível com OpenAI na máquina da pessoa: Ollama, LM Studio, vLLM ou uma API na nuvem como o OpenRouter. Os apps o chamam pela API da OpenAI. |
| **Participante de harness** | Um agente de código (Claude Code, Codex ou OpenCode) rodando na máquina da pessoa, com o login dela. Os apps se conectam a ele e trocam mensagens ACP. |
| **Túnel** | O WebSocket que um participante abre até o hub. Todo o tráfego dele passa por ali, então o provedor pode ficar em `localhost`. |
| **Seu app** | Seu código. Ele chama a sala pelo [SDK](/pt-br/reference/sdk/) ou por qualquer cliente compatível com OpenAI e decide o que o grupo faz. |

:::caution[Somente redes confiáveis]
O hub não tem autenticação embutida. Rode-o em uma rede onde você confia em todo mundo: sua casa, seu laboratório, a sala onde seu grupo se reúne.
:::

Se você já usa um agente de código, ele pode fazer a configuração com você. Ele pergunta o que você quer compartilhar e confere no final se tudo responde.
