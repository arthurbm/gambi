---
title: Build a custom participant runtime
description: Use createParticipantSession() to run your own participant process when the CLI is not enough.
---

The `gambi participant join` CLI covers the common case: pick a model, point at a hub, stay online. When you need more control, build your own runtime on top of `createParticipantSession()`. Examples: embedding the participant in a long-running service, adding custom shutdown logic, or running several participants in one process.

This guide shows the minimum runtime that behaves like the CLI, then the common extensions.

## Before you start

You need:

- a Gambi hub you can reach (`gambi hub serve`)
- an existing room code (`gambi room create --name "Demo"`)
- a local OpenAI-compatible provider endpoint (Ollama, LM Studio, vLLM, or anything else that serves `/v1/models` and `/v1/chat/completions`)
- `gambi-sdk` installed

```bash
bun add gambi-sdk
```

## Step 1: Open a session

`createParticipantSession()` does four things in one call: it probes your endpoint, registers the participant, opens the tunnel, and starts the heartbeat and ping loops.

```ts
import { createParticipantSession } from "gambi-sdk";

const session = await createParticipantSession({
  hubUrl: "http://localhost:3000",
  roomCode: "ABC123",
  participantId: "worker-1",
  nickname: "worker-1",
  endpoint: "http://localhost:11434",
  model: "llama3",
});

console.log("registered as", session.participant.id);
```

If the endpoint does not expose the requested model, the call throws before anything is registered. Treat that as a configuration error and exit.

## Step 2: Wait for the session to close

`session.waitUntilClosed()` resolves with a close event the moment the runtime stops, whatever the reason.

```ts
const closeEvent = await session.waitUntilClosed();
console.log("session ended:", closeEvent.reason);
```

Three close reasons, each with a different meaning:

| Reason | Meaning | Suggested action |
| --- | --- | --- |
| `"closed"` | your code called `session.close()` | exit cleanly |
| `"heartbeat_failed"` | a management heartbeat request failed; one failure closes the session | the hub is probably unreachable. Exit and let your supervisor restart the runtime |
| `"tunnel_closed"` | the WebSocket tunnel closed or errored, from either side | often transient network trouble. Create a new session with the same participant ID |

`closeEvent.error` holds the underlying `Error` when there is one. Log it.

The session never reconnects by itself. On `"closed"` and `"heartbeat_failed"` it tries to remove the participant from the room before it resolves. On `"tunnel_closed"` it does not: the registration stays, and the hub marks the participant offline as soon as its tunnel closes. Calling `createParticipantSession()` again with the same participant ID updates that registration and opens a new tunnel.

## Step 3: Shut down cleanly

The SDK does not install signal handlers. Wire `session.close()` to `SIGINT` and `SIGTERM` yourself. `close()` closes the tunnel and removes the participant from the room before it returns.

```ts
for (const signal of ["SIGINT", "SIGTERM"] as const) {
  process.on(signal, () => {
    void session.close();
  });
}
```

If the session already ended with `"tunnel_closed"`, `close()` returns that close event and does not remove the registration. Call `client.participants.remove()` from the [management client](/reference/sdk/#clientparticipantsremoveroomcode-participantid) if you need it gone at once.

## Step 4: Forward provider auth

`authHeaders` apply only when the runtime calls your provider endpoint. They never leave the participant runtime. Use them for API keys or bearer tokens your provider needs.

```ts
const session = await createParticipantSession({
  hubUrl: "http://localhost:3000",
  roomCode: "ABC123",
  participantId: "worker-1",
  nickname: "worker-1",
  endpoint: "http://localhost:11434",
  model: "llama3",
  authHeaders: {
    Authorization: `Bearer ${process.env.PROVIDER_TOKEN}`,
  },
});
```

The hub never sees `PROVIDER_TOKEN`.

## Step 5: Common customizations

### Declare machine specs

The TUI shows specs, and room events include them. Pass them when you know them. The fields are `cpu`, `gpu`, `ram` (GB), and `vram` (GB), all optional:

```ts
await createParticipantSession({
  // ...
  specs: {
    cpu: "Apple M2 Pro",
    ram: 32,
    gpu: "Apple M2 Pro integrated",
  },
});
```

### Override capabilities

The probe auto-detects which OpenAI-compatible surfaces your endpoint supports. Override when you want the hub to prefer a specific one:

```ts
await createParticipantSession({
  // ...
  capabilities: {
    openResponses: "supported",
    chatCompletions: "supported",
  },
});
```

### Joining a password-protected room

```ts
await createParticipantSession({
  // ...
  password: process.env.ROOM_PASSWORD,
});
```

### Running more than one participant in one process

Call `createParticipantSession()` once per participant. Each call returns an independent session with its own tunnel, heartbeat loop, and participant identity. Run their `waitUntilClosed()` promises in parallel.

```ts
const sessions = await Promise.all([
  createParticipantSession({ /* worker-1 */ }),
  createParticipantSession({ /* worker-2 */ }),
]);

await Promise.allSettled(
  sessions.map((session) => session.waitUntilClosed())
);
```

## A complete runtime

Putting it all together:

```ts
import { createParticipantSession } from "gambi-sdk";

const session = await createParticipantSession({
  hubUrl: process.env.GAMBI_HUB ?? "http://localhost:3000",
  roomCode: "ABC123",
  participantId: "worker-1",
  nickname: "worker-1",
  endpoint: "http://localhost:11434",
  model: "llama3",
  authHeaders: process.env.PROVIDER_TOKEN
    ? { Authorization: `Bearer ${process.env.PROVIDER_TOKEN}` }
    : undefined,
});

for (const signal of ["SIGINT", "SIGTERM"] as const) {
  process.on(signal, () => {
    void session.close();
  });
}

const { reason, error } = await session.waitUntilClosed();
console.log("[gambi] session ended:", reason);
if (error) {
  console.error(error);
}
process.exit(reason === "closed" ? 0 : 1);
```
