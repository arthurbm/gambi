# v0.7.1 release draft

Status: pending. Run the release workflow only from `main` after the fix for issue #82 merges.

## Release notes

Gambi 0.7.1 fixes the type declarations published with `gambi-sdk`.

- The `.d.ts` files in `gambi-sdk` 0.6.0 and 0.7.0 imported `@gambi/core/*`, a workspace package that is not on npm. With `skipLibCheck` on, every SDK type became `any` without a warning; with it off, `tsc` failed with `TS2307`. The SDK now ships bundled declarations (`dist/index.d.ts`, `dist/discovery.d.ts`, and one shared chunk) with no `@gambi/core` import ([#82](https://github.com/arthurbm/gambi/issues/82)).
- `gambi-sdk` now lists `@ai-sdk/provider` and `openai` as dependencies. The JavaScript bundle already imported `@ai-sdk/provider` at runtime, and the declarations reference `openai` types such as `ChatCompletion` and `Response`.
- `Hub["server"]` is typed through `globalThis`, so the declarations compile under Node. Under Bun it is the same server type as before; where Bun's types are not loaded it is `unknown`.
- CI packs the SDK and type-checks a clean npm consumer with `skipLibCheck` off and on (`bun run --cwd packages/sdk check:packed-types`).

Consumers with `skipLibCheck` off also need `@types/json-schema`, because the declarations of `@ai-sdk/provider` import `json-schema` without depending on its types. That is upstream and unchanged by this release.

## Post-merge release checklist

1. Validate the `main` commit that will be released:

   ```bash
   bun install --frozen-lockfile
   bun run check-types
   bun test packages/sdk
   bun run --cwd packages/sdk build
   bun run --cwd packages/sdk check:packed-types
   ```

2. Dispatch the release workflow with a patch bump from `main`:

   ```bash
   gh workflow run release.yml --ref main -f bump=patch
   gambi_release_run_id=$(gh run list --workflow=release.yml --branch main --limit 1 --json databaseId --jq '.[0].databaseId')
   gh run watch "$gambi_release_run_id" --exit-status
   ```

   Confirm the workflow's `version` job calculated `0.7.1`. Do not edit any `package.json` version by hand.

3. Verify the npm package set and GitHub Release:

   ```bash
   npm view gambi@0.7.1 version
   npm view gambi-sdk@0.7.1 version
   npm view gambi-tui@0.7.1 version
   npm view gambi-linux-x64@0.7.1 version
   npm view gambi-linux-arm64@0.7.1 version
   npm view gambi-darwin-arm64@0.7.1 version
   npm view gambi-darwin-x64@0.7.1 version
   npm view gambi-windows-x64@0.7.1 version
   gh release view v0.7.1 --json tagName,isDraft,isPrerelease,assets,url
   ```

4. Type-check the published SDK from a clean consumer:

   ```bash
   bun run --cwd packages/sdk check:packed-types 0.7.1
   ```
